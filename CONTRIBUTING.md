# Contributing

Thank you for helping improve BluePrint.

## What this repository accepts

This repository carries the released binaries, the documentation and the sample
projects. The library source is not developed here, so a change to how BluePrint
behaves cannot be made in a pull request against this repository.

**Accepted**

- documentation fixes: anything unclear, wrong, or out of date
- improvements to the sample projects in `Demo/`
- installation and usage examples
- issue and pull request templates, and general repository upkeep

**Not accepted**

- changes to the BluePrint library source

## Reporting a bug

Open an issue. The more of this you can give, the faster it gets fixed:

- the package name and version, or the Studio version
- the target framework you were building for
- what you expected and what happened instead
- the smallest report definition or code that shows the problem

A fix reaches you as a new package version, or a new Studio build.

## Pull requests

1. Branch from `main`.
2. Change only documentation or files under `Demo/`.
3. Explain what the change does and why it is needed.
4. If you changed a sample, say which package version you built it against.
5. Keep the summary short and specific.

## House rules

- Everything here is written in English.
- Never commit a secret, and never commit an internal host name or address.
- Say plainly what a change does not cover. A documented limit is worth more than
  an optimistic claim.
